# 索引文件模板与更新规范

> 索引仅作纯目录指引，每个条目只保留「文件名 + 一句话用途说明」，不记录版本/日期/归档状态等修改细节。

---

## 一、索引文件体系

设计归档涉及两层索引，归档操作**必须同步更新全部两层**：

```
┌─────────────────────────────────────────────────────┐
│  L1: UI设计子目录索引                                │
│  02.项目知识图谱/2.UI/索引.md                        │
│  └── UI设计资产的全局导航                            │
├─────────────────────────────────────────────────────┤
│  L2: 迭代区索引                                      │
│  {迭代目录}/2.UI/索引.md                             │
│  └── 单次迭代的设计产出清单（仅2.UI/下产出物，不含tmp）│
└─────────────────────────────────────────────────────┘
```

> **tmp不纳入索引**：tmp内容不推送到 git 仓库，L2 索引仅记录 `2.UI/` 下的产出物。

---

## 二、L1 - UI设计子目录索引

### 2.1 文件位置

`02.项目知识图谱/2.UI/索引.md`

### 2.2 格式模板

```markdown
# UI设计资产索引

## 设计稿/

### 唯一入口与公共资源
- index.html — MPA首页/默认入口（含业务内容 + 导航壳挂载点）
- css/common.css — 公共样式（Design Tokens + 导航壳 + 系统级页签）
- js/common.js — 公共JS（菜单配置+图标Sprite+pageRoute路由+switchPage+sessionStorage持久化+zoom）

### pages/（页面HTML，按模块归类）

#### {模块名}
- pages/{模块名}/D-001_{页面名}.html — {一句话用途说明}
- pages/{模块名}/D-002_{页面名}.html — {一句话用途说明}

#### {模块名2}
- pages/{模块名2}/D-005_{页面名}.html — {一句话用途说明}

### js/pages/（页面配套JS，按模块归类，与 pages/ 同构）

#### {模块名}
- js/pages/{模块名}/D-001_{页面名}.js — 配套JS
- js/pages/{模块名}/D-002_{页面名}.js — 配套JS

#### {模块名2}
- js/pages/{模块名2}/D-005_{页面名}.js — 配套JS

## 设计文档/
- {模块名}-设计说明.md — {一句话用途说明}

## 素材资源/
- {模块名}/ — {说明}
```

### 2.3 条目格式

- 每个条目一行：`- {文件名} — {一句话用途说明}`
- 文件名含相对路径前缀（如 `pages/{模块名}/D-001_xxx.html`、`js/pages/{模块名}/D-001_xxx.js`）
- 用途说明不超过一句话，描述该产物的功能/内容

## 三、L2 - 迭代区索引

### 3.1 文件位置

`{迭代目录}/2.UI/索引.md`

### 3.2 格式模板

```markdown
# {迭代名称} - UI设计索引

## 2.UI/
- index.html — MPA首页/默认入口
- css/common.css — 公共样式（Design Tokens + 导航壳 + 系统级页签）
- js/common.js — 公共JS（菜单配置+图标Sprite+路由+switchPage+sessionStorage持久化+zoom）
- pages/D-001_{页面名}.html — {一句话用途说明}
- js/pages/D-001_{页面名}.js — 配套JS
- pages/D-002_{页面名}.html — {一句话用途说明}
- js/pages/D-002_{页面名}.js — 配套JS
```

> **不含tmp**：tmp与产出物平级在 `2.UI/` 下，但不推送到 git 仓库，不纳入索引。

### 3.3 更新操作

归档完成后，将本次归档的产物条目补充到 L2 索引（若文件不存在则按模板新建）。

---

## 四、新建索引文件

当目标目录不存在索引文件时，按上述模板创建。

优先级：
1. 若同级有其他迭代的索引文件 → 参照其格式创建
2. 若无参照 → 使用本模板的标准格式创建
