# 任务收尾

> 前置：禅道闭环已处理（无单号直接进入本技能）。复盘固化（learn）已前置到合并推送前完成，固化文档随代码推送；终验/闭环期如有补充固化，须已提交推送。收尾是**会话最后一步**：只做交付态收口，不回改已推送代码，本步骤之后不再产生新的仓库写入。

## 遗留事项登记与说明

- **数据现状类遗留必须说明**：如某字段 UAT 全空需有值数据后才能完整验证、某环境未同步等，写明现状 + 补齐条件 + 影响的验证终点
- **拍板未含的同类遗留项**：前期确认/同类排查中用户未纳入本次处理范围的项，逐条登记（位置、场景、处理建议），交任务说明留存
- **用户选「仅本次实例」的缺陷**：其余同类实例登记为遗留，注明后续触发条件
- 遗留表述与实际处理一致，禁止把「未做」写成「已确认无影响」

## 验证表述口径

- 验证表述不超出实际覆盖终点：接口返回正确 ≠ 页面回显正确
- 「验证通过/全链路打通」必须覆盖用户操作完整链路终点且逐项附证据（证据要求见 `e2e-ops` 技能）；无证据的项按未验证表述
- 数据现状类遗留对应的验证范围，明确写「待数据补齐后复验」

## 临时文件清理

- 清理对象：导出验证文件与解压目录、临时 SQL/调试脚本/日志、提交信息临时文件、树内测试产物
- 凭据恢复类临时产物（如 acl-backup-*.json/.ps1、acl-report-*.jsonl 及其所在目录）任务结束即删，禁止遗留原地
- 收尾统一复查工作区与下载目录无遗留；树盘点与回收按 `worktree-ops`（无独有提交 + 工作区干净的树才回收）
- 密码管理器中的任务级临时凭据条目一并清理，禁止遗留明文凭据

## 工作区 git 收口

- `git status --short` 复查三个仓库：外层 jomoo-ai-coding、pms、pms_frontend，确认无未提交改动与未跟踪临时文件
- 存在未提交改动（含 learn 或其他步骤写入项目仓库的文档）→ 立即提交推送（中文提交信息，pms/pms_frontend 提交在 uat 分支），三仓库全清才算收口完成
- 本步骤是兜底闸门：任何前置步骤遗留的仓库写入都在此落地，之后会话结束
