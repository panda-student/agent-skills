## 🏷️ 零、品牌资源 (brand)

> **用途**：存放 JMBOS 品牌标识（Logo）相关资源，支持动态变色
>
> **触发时机**：生成包含顶部导航栏的页面时，必须加载 Logo

### 0.1 文件清单

**路径**: `brand/`

| 文件名 | 格式 | 用途 | 快速访问 |
|--------|------|------|---------|
| `logo（支持替换颜色）.svg` | **SVG（首选）** | 主Logo文件，支持 CSS filter 动态变色 | [查看](./brand/logo（支持替换颜色）.svg) |
| `logo（主题色）.png` | PNG | 品牌色(#0C328C)Logo，位图备用 | [查看](./brand/logo（主题色）.png) |
| `logo（白色）.png` | PNG | 白色Logo，深色背景直接使用 | [查看](./brand/logo（白色）.png) |
| `README.md` | 文档 | Logo 图片使用规范（v2.5.0） | [查看](./brand/README.md) |

### 0.2 使用要点

- ✅ **首选方案**：使用 `logo（支持替换颜色）.svg` + `<img>` 标签 + CSS `filter: brightness(0) invert(1)` 实现动态变色
- ✅ **深色背景**（#0C328C 导航栏）：`filter: brightness(0) invert(1)` → Logo 显示白色
- ✅ **浅色背景**（白色/浅灰）：`filter: none` → Logo 显示品牌色(#0C328C)
- ⚠️ PNG 格式不支持动态变色，仅作降级方案
- 📖 **完整规范**：详见 [brand/README.md](./brand/README.md)（v2.5.0）
