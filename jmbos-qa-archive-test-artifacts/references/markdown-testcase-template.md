# Markdown 测试用例模板

## 格式说明

本模板用于生成可导入 XMind 的 Markdown 格式测试用例。

### 层级结构

```
## 模块名称
### 场景名称
#### [P{优先级}] TC-{序号} {用例标题}
- 前置条件：{前置条件内容}
  - 测试步骤：{测试步骤内容}
    - 预期结果：{预期结果内容}
```

### 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 优先级 | P0/P1/P2 | [P0] |
| 序号 | 三位数字，从001开始 | TC-001 |
| 用例标题 | 简洁描述测试目的 | 验证登录功能 |

### 内容格式规则

1. **前置条件、测试步骤、预期结果** 使用列表缩进形成父子层级
2. **内容不换行**，多条内容用分号 `;` 分隔
3. **预期结果** 不包含优先级标记

### 示例

```markdown
#### [P0] TC-001 验证树形层级正确性

- 前置条件：1. 条件1; 2. 条件2; 3. 条件3
  - 测试步骤：1. 步骤一; 2. 步骤二; 3. 步骤三
    - 预期结果：结果描述
```
