# API 自动化覆盖清单模板

> 本模板定义迭代工作区和全局知识图谱中 API 自动化覆盖清单的标准格式。

## 一、迭代工作区清单

文件位置：`{迭代目录}/4.测试/自动化测试/API/api_{project}_coverage.md`

### 格式

```markdown
# {project} API 自动化覆盖清单

## 基本信息

| 字段 | 值 |
|------|------|
| 所属项目 | {project} |
| 所属迭代 | {YYYYMMDD-迭代名称} |
| 最后更新 | YYYY-MM-DD |

## 覆盖明细

| 功能模块 | 关联接口 | 用例脚本路径 | 所属迭代 | 创建时间 | 操作类型 |
|----------|----------|-------------|----------|----------|----------|
| 用户管理 | POST /api/user/create | cases/api/{project}/user/test_create_user.py | 20260512-门店区域提报优化 | 2026-05-12 | 新增 |
| 用户管理 | POST /api/user/delete | cases/api/{project}/user/test_delete_user.py | 20260512-门店区域提报优化 | 2026-05-12 | 新增 |
| 订单管理 | GET /api/order/query | cases/api/{project}/order/test_query_order.py | 20260101-迭代需求名称 | 2026-01-15 | 修改 |
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 功能模块 | 是 | 接口所属业务模块名称 |
| 关联接口 | 是 | HTTP 方法 + 接口路径，如 `POST /api/user/create` |
| 用例脚本路径 | 是 | AutomationTest 项目中用例文件的相对路径 |
| 所属迭代 | 是 | 当前迭代名称 |
| 创建时间 | 是 | 该记录首次创建日期，格式 YYYY-MM-DD |
| 操作类型 | 是 | 新增 或 修改 |

### 更新规则

1. **新增接口**：在表格末尾追加新行，操作类型为"新增"。
2. **修改接口**：按"关联接口 + 功能模块"匹配已有行，更新对应行内容。保留原创建时间，操作类型改为"修改"。
3. **禁止覆盖**：不允许清除已有记录，只做增量更新。

## 二、全局知识图谱清单

文件位置：`ai_workspace/02.产品知识图谱/4.测试/自动化覆盖清单/API自动化/api_{project}_coverage.md`

### 格式

与迭代清单格式一致，额外在基本信息中增加：

```markdown
## 基本信息

| 字段 | 值 |
|------|------|
| 所属项目 | {project} |
| 最后更新 | YYYY-MM-DD |
| 累计覆盖接口数 | N |
```

### 维护规则

1. 全局清单由归档流程维护。
2. 迭代归档时，将迭代清单中的记录合并到全局清单。
3. 合并规则：按"关联接口 + 功能模块"匹配，已有则更新，无则追加。
4. 合并后更新"最后更新"时间和"累计覆盖接口数"。
