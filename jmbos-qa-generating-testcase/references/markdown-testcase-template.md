# Markdown 测试用例模板

## ⚠️ 生成前必读 - 强制检查清单

生成测试用例文件前，**必须**确认以下检查项全部通过：

- [ ] 最终文件**仅包含**用例列表和假设与未决事项
- [ ] **不包含**文档信息表格（如需求名称、需求来源、生成日期等）
- [ ] **不包含**需求溯源表
- [ ] **不包含**统计信息表格（如用例数量统计、覆盖率统计等）
- [ ] **不包含**覆盖率矩阵
- [ ] **不包含**其他非用例列表的辅助性内容

> **重要提示**：上述禁止内容只应放在 `.temp/{需求名称}/reports/` 目录下的中间产物文件中，**严禁**出现在最终测试用例文件！

---

## 格式说明

本模板用于生成可导入 XMind 的 Markdown 格式测试用例。

### 层级结构

```
# {需求名称}-测试用例
## 模块名称（如：质量保障）
### 菜单名称（如：用例列表、测试任务、执行历史）
#### 场景名称（如：左侧树形展示、查询功能）
##### [P{优先级}] TC-{模块名拼音首字母}-{序号} {用例标题}
- 前置条件：{前置条件内容}
  - 测试步骤：{测试步骤内容}
    - 预期结果：{预期结果内容}
```

### 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 优先级 | P0/P1/P2 | [P0] |
| 模块名拼音首字母 | 所属模块名称的拼音首字母（中文取首字母，英文保持不变，数字保持不变，特殊字符全部删除，转换后全部大写） | 质量保障→QAZLBZ、QA工作台→QAGZT、用户管理V2→YHGLV2、订单&支付→DDZF、订单-支付→DDZF |
| 序号 | 三位数字，从001开始 | 001 |
| 用例标题 | 简洁描述测试目的 | 验证登录功能 |

### 内容格式规则

1. **前置条件、测试步骤、预期结果** 使用列表缩进形成父子层级
2. **内容不换行**，多条内容用分号 `;` 分隔
3. **预期结果** 不包含优先级标记

### 文件内容规范

> 详见上方【⚠️ 生成前必读 - 强制检查清单】，最终文件仅包含用例列表和假设与未决事项。

### 示例

```markdown
## 质量保障
### 用例列表
#### 左侧树形展示
##### [P0] TC-QAZLBZ-001 验证树形层级正确性

- 前置条件：1. 条件1; 2. 条件2; 3. 条件3
  - 测试步骤：1. 步骤一; 2. 步骤二; 3. 步骤三
    - 预期结果：结果描述
```
