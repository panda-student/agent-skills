📖 使用说明

⚠️ 重要提醒（生产环境必读）

此页面通过 fetch() 动态加载 Sprite 文件，仅适用于 HTTP 服务器环境（本地双击打开会报错）。

生产环境的唯一正确方式：将 icons-sprite.svg 的完整内容内嵌到 HTML 中（见下方步骤1）， 禁止使用 <object> / 外联 <use xlink:href> 等方式（无法支持图标动态变色）。

📖 完整规范详见：icons/README.md

1️⃣ 在页面中引入 Sprite 文件（✅ 唯一推荐：内联方式）

<body>
  <!-- SVG Sprite 图标库（从 icons-sprite.svg 复制完整内容到这里） -->
  <svg xmlns="http://www.w3.org/2000/svg" style="display: none;">
    <symbol id="icon-edit" viewBox="0 0 16 16">
      <path d="..." fill="currentColor"/>
    </symbol>
    <!-- ... 其他117个图标 symbol ... -->
  </svg>

  <!-- 页面其他内容... -->
</body>

2️⃣ 使用图标（点击上方任意图标可快速复制代码）

<svg class="icon">
  <use href="#icon-edit"></use>
</svg>

3️⃣ 通过 CSS 控制颜色（支持 hover 等交互效果）

.my-button {
  color: #333333; /* 默认颜色 */
}

.my-button:hover {
  color: #3685F2; /* hover 时自动变蓝色 */
}
✅ 为什么必须内联？
  • ✅ 支持动态变色：内联后可通过父元素 color 属性控制图标颜色（currentColor 继承机制）
  • ✅ 离线可用：双击 HTML 文件即可查看，无需启动服务器
  • ❌ <object> 标签：创建独立文档上下文，currentColor 无法继承，图标不能变色
  • ❌ 外联 <use xlink:href>：浏览器安全策略阻止 file:// 协议跨文件加载
